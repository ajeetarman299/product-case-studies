# Release sign-off checklist

How I decide a feature is ready to ship. The default answer is "not yet" until each item is proven.

1. **Test the exact screen the ticket names.** A look-alike view passing proves nothing.
2. **Use it, don't just look at it.** A button that renders is not a button that works. Click it and check the result.
3. **Prove every acceptance criterion end to end.** Partial proof is a fail.
4. **Lead with the faults.** List what is broken or unproven before what works.
5. **Record results as a table.** One row per item: criterion, result, evidence.
6. **Sign off item by item.** Production deployment waits until every item has its own sign-off.
